# Stock Inventory Ultimate Pro

ឯកសារ / Files:
- `index.html` – ទំព័រចម្បង
- `css/style.css` – រចនាបថ
- `js/tailwind-config.js` – Tailwind config
- `js/app.js` – Logic កម្មវិធី

## Deploy លើ GitHub Pages
1. បង្កើត repository ថ្មី លើ GitHub
2. Upload ឯកសារទាំងអស់ (រក្សារចនាសម្ព័ន្ធ folder)
3. Settings → Pages → Source: `Deploy from a branch` → Branch: `main` / `(root)` → Save
4. បើកតំណ `https://<username>.github.io/<repo>/`
